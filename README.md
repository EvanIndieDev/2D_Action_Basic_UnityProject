# Unity 2D Action Game – Learning Series

This repository is part of a YouTube tutorial series where we build a **2D action game in Unity from scratch**.

The goal of this project is not to create a perfect or overly complex architecture, but to **learn Unity and C# step by step by actually making a game**.

---

## 🎯 Who This Series Is For

This series is designed for:

* Complete beginners with **no Unity experience**
* Learners with **no prior C# knowledge**
* Indie game enthusiasts who want to understand how a 2D action game works
* Developers who prefer learning by **building real features**, not just watching theory

You don’t need any background in game development to get started.

---

## 🕹️ What We Are Building

Over the course of this series, we will gradually build a playable 2D action game, including:

* Player movement and controls
* Animations and state machines
* Combat and hit detection
* Enemies and basic AI behaviors
* A complete boss fight
* A clean and understandable project structure

Each episode focuses on **one clear topic**, keeping videos short and beginner-friendly.

---

## 📚 What You Will Learn

* Unity Editor basics and workflow
* Core C# concepts through real use cases
* How GameObjects and Components work together
* Finite State Machines (FSM) in practice
* Combat systems and damage handling
* Structuring scripts in a growing project

Most importantly, you’ll learn **how to think like a game developer**, not just how to copy code.
